## 项目初始化：开发者门户网站

完成了基于 Vue 3 + TypeScript 的个人开发者门户网站项目脚手架搭建。

### 技术栈
- Vue 3 (Composition API + `<script setup lang="ts">`)
- TypeScript (vue-tsc 类型检查通过)
- Vite 5 (构建工具)
- Vue Router 4 (多页面路由，路由懒加载)
- Tailwind CSS 3 (原子化 CSS + 语义化主题 token)

- Pinia (状态管理：theme store + locale store)
- Vue I18n 9 (国际化：zh-CN 默认 + en-US 预留)
- @vueuse/core (组合式工具)

- 结构化数据放在 src/data/（projects, skills, experience, blog, navigation, social）
- 共享类型放在 src/types/
- Hooks: useTheme, useLocale, useSeo, useBreakpoint

## Vite 5 → 6 升级（Cloudflare Wrangler 部署要求）

- Cloudflare Wrangler 2.0+ 要求 Vite >= 6.0.0，否则部署报错
- 升级包：
  - `vite`: `^5.3.3` → `^6.0.0`
  - `@vitejs/plugin-vue`: `^5.0.5` → `^5.2.0`（Vite 6 最低要求）

- `vite-plugin-stylelint@5.3.1` 仅声明 peer Vite ≤ 5，使用 `--legacy-peer-deps` 安装（该插件仅 dev 模式运行，不影响生产构建）

## 18:09 — 修复语言切换时顶部菜单栏语言按钮不同步

**问题**：切换语言后，顶部 LocaleSwitcher 按钮文字和下拉选项不随语言变化同步更新。

**根因**：
- `LocaleSwitcher.vue` 中 `options` 是普通 `const` 数组（非响应式），Naive UI NDropdown 缓存旧渲染结果
- `shortLabel()` 是普通函数，响应式链路不够直接

**修改**：
1. `src/components/common/LocaleSwitcher.vue`
   - `options` 改为 `computed`，语言切换时重新计算 label 函数
   - `shortLabel()` 替换为 `computed` 属性 `buttonLabel`
   - `NDropdown` 添加 `:key="locale"`，语言变化时强制重建组件
2. `src/stores/locale.ts`
   - 清理 `i18n.global.locale` 的类型断言，改用 `.value` 直接赋值

**验证**：vue-tsc typecheck 通过，vite build 成功（10.87s）
