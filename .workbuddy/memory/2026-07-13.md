# 2026-07-13 工作日志

## 项目初始化：开发者门户网站

完成了基于 Vue 3 + TypeScript 的个人开发者门户网站项目脚手架搭建。

### 技术栈
- Vue 3 (Composition API + `<script setup lang="ts">`)
- TypeScript (vue-tsc 类型检查通过)
- Vite 5 (构建工具)
- Vue Router 4 (多页面路由，路由懒加载)
- Tailwind CSS 3 (原子化 CSS + 语义化主题 token)
- Naive UI (组件库，主题同步)
- Pinia (状态管理：theme store + locale store)
- Vue I18n 9 (国际化：zh-CN 默认 + en-US 预留)
- @vueuse/core (组合式工具)

### 项目结构
- 10 个路由页面（Home, About, Projects, ProjectDetail, Blog, BlogDetail, Playground, Opensource, Resume, Contact, NotFound）
- 主题系统支持 light/dark/system 三模式，通过 CSS variables + Tailwind dark mode + Naive UI 主题同步
- 国际化系统通过 Pinia store 同步 vue-i18n 实例
- 结构化数据放在 src/data/（projects, skills, experience, blog, navigation, social）
- 共享类型放在 src/types/
- Hooks: useTheme, useLocale, useSeo, useBreakpoint
- Business 组件: ProjectCard, SkillBadge, ExperienceTimeline

### 配置文件
- tsconfig.json (移除 baseUrl，使用 paths 相对路径)

### Stylelint 修复
- `main.css`: 修复 22 个 stylelint 错误
